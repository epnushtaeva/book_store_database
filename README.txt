
Задание:
1. Написать консольное приложение для библиотеки. В котором есть следующие сущности: Автор, Книга, Читатель.
2. Добавить возможность создания, обновления и удаления для каждой сущности.
3. Добавить возможность просмотра списка сущностей и каждой сущности в отдельности.
4. Добавить возможность бронирования книг читателями и снятия брони книг.
5. Добавить возможность просмотра забронированных книг.
6. В разработке по возможности использовать принципы SOLID, DRY, KISS.
7. Вынести логику хранения сущностей в отдельные репозитории.
8. Отдельно написать Writer, для вывода сущностей в консоль и Reader для заполнения сущностей из консоли.
Запуск приложения:
Перед запуском необходимо установить и запустить MySQL сервер
Затем необходимо на сервере MySQL создать базу данных и таблицы. Для этого нужно в HeidiSQL или в любом другом ПО для 
администрирования БД запустить скрипт create_database.sql. Скрипт находится в корне проекта
После установки SQL сервера и создания БД, неоюходимо заполнить файл settings.ini в корне проекта.
В нем необходимо указать адрес сервера, где установлен MySQL, название базы данных, имя пользователя и пароль для подключения к БД.
Затем необходимо запустить проект, выполнив следующие команды:
composer install
php index.php

Версия PHP: 8.5
